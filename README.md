# 🛡️ PhishGuard

## Cybersecurity Awareness & Phishing Simulation Platform

PhishGuard is an authorized cybersecurity awareness project designed to demonstrate common phishing and social engineering techniques in a controlled educational environment.

The project demonstrates how a realistic promotional email can lead a user to a simulated login page and then provide cybersecurity awareness education about suspicious links, fake login pages, and credential safety.

---

## 🎯 Project Objective

The primary objective of PhishGuard is to educate users about phishing risks and demonstrate how attackers may use:

* Attractive promotional offers
* Familiar-looking branding
* Professional email designs
* Login pages
* Social engineering techniques
* Suspicious links

to influence users into interacting with potentially unsafe websites.

This project is strictly designed for authorized educational and cybersecurity awareness purposes.

## 🧩 Project Components

### 1. Promotional Email Simulation

A custom HTML promotional email was created for the simulation.

The email uses a used-car marketplace scenario and includes:

* Custom car-themed branding
* Vehicle listings
* Discount offers
* Pricing in Indian Rupees
* Call-to-action buttons
* Responsive layout
* Mobile compatibility

The email is designed to demonstrate how attractive offers and familiar-looking branding can influence user behavior.

---

### 2. GoPhish Campaign Simulation

GoPhish was used to manage the controlled cybersecurity awareness campaign.

The campaign workflow includes:

```text
Campaign
    ↓
Email Template
    ↓
Landing Page
    ↓
Campaign Link
    ↓
User Interaction
```

The HTML email template uses GoPhish dynamic placeholders such as:

```text
{{.URL}}
```

This allows campaign links to be dynamically generated by GoPhish.

The template also contains:

```text
{{.Tracker}}
```

for campaign tracking functionality.

---

### 3. Simulated Login Page

A custom HTML landing page was created for the awareness simulation.

The page contains:

* A simulated login interface
* Email input field
* Password input field
* Show/hide password functionality
* Training simulation notice
* Awareness result screen
* Cybersecurity education message

The interface demonstrates how a professional-looking login page can influence a user's trust.

---

### 4. Awareness Result

After the simulated interaction, the user receives an awareness message explaining important cybersecurity practices.

The awareness message teaches users to:

* Check website addresses carefully
* Verify the domain name
* Be careful with unexpected links
* Avoid entering passwords into unknown websites
* Understand that familiar logos do not prove authenticity

---

## 🔐 Privacy and Safety

This project is designed as a controlled cybersecurity awareness simulation.

The landing page is designed so that the form interaction is handled locally in the browser.

The project does not intentionally collect, store, or transmit real credentials.

Users should never enter real passwords or real account credentials into this demonstration.

PhishGuard should only be used for:
